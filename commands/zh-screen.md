使用者想問的(可為空):$ARGUMENTS

你要幫看不懂英文介面的人看懂螢幕。資料來源:本 plugin 的 `references/screen-map.md`(完整路徑在 session 開頭【zh-tw-guide】提醒;找不到就 Glob `**/zh-tw-guide/references/screen-map.md`)。

**有指定東西時**(例:「Artifacts 是什麼」「Background tasks」)
→ 只答那一項:中文名 + 一句白話用途 + 什麼時候會用到。三行內講完,不要整張表倒出來。

**沒指定時**
→ 秀對照卡,但**分區塊、一次給一塊**,不要一口氣倒完:
1. 先給「左邊那排(側邊欄)」的表格
2. 問一句:「還要看輸入區、右上角背景任務,還是 Code 分頁?」
3. 使用者說要哪塊再給哪塊

**格式**
- 用表格:英文 | 中文 | 白話說明
- 英文原文保留(他要能對得上螢幕),中文放旁邊
- 白話說明要講「幹嘛用的」,不是只翻字面

**收尾一句**(每次都講,這是新手最需要的安全感)
「看不懂的東西直接問我,或按 `Esc` 中斷、權限詢問可以說不 —— 弄不壞的。」

**鐵律**
- 畫面會隨版本改。對照卡跟他螢幕不符時,以他看到的為準,請他描述或截圖,不要硬套。
- guided 模式可加一句花生的話當開場(最多一句)。
