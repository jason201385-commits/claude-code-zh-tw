# 畫面繁中對照卡

> 給看不懂英文介面的人:每個東西**叫什麼、是幹嘛的、什麼時候會用到**。
> ⚠️ Claude 改版很快,畫面跟這裡對不上時**以你螢幕上看到的為準**;找不到的東西直接問我。

## 左邊那排(側邊欄)

| 英文 | 中文 | 白話說明 |
|---|---|---|
| **Home** | 首頁 | 一般聊天的地方。問問題、寫東西、查資料都在這 |
| **Code** | 寫程式 | 讓 Claude 直接動你電腦裡的檔案。**要先選一個資料夾**它才知道要動哪裡 |
| **New** | 開新的 | 開一個全新對話。跟上一個對話完全無關(它不會記得剛才聊什麼) |
| **Artifacts** | 作品 | Claude 幫你做出來的成品(網頁、圖表、文件)會存在這 |
| **Routines** | 例行任務 | 排定時間自動執行的任務(例如每天早上幫你整理信件) |
| **Dispatch** | 派工 | 把工作丟給 Claude 在雲端跑,你可以關掉視窗去做別的 |
| **Customize** | 個人化 | 調整 Claude 的回答風格、記住你的偏好 |
| **More** | 更多 | 展開看其他功能 |
| **Settings** | 設定 | 帳號、外觀、語言、連接器都在這 |

側邊欄下半部是**你的對話清單**(最近聊過的),點一下就回到那個對話。

## 中間下面(輸入區)

| 英文 | 中文 | 白話說明 |
|---|---|---|
| **Type / for commands** | 打 / 看指令 | 就是打字的地方。**直接打中文**就好;想看有哪些快速指令,先打一個 `/` |
| **Auto** | 自動 | 讓 Claude 自己決定用哪個模型。不確定就維持這個 |
| **＋** | 加東西 | 附加檔案、圖片、資料夾 |
| **🎤** | 語音 | 用講的代替打字 |

## 右上角

| 英文 | 中文 | 白話說明 |
|---|---|---|
| **Background tasks** | 背景任務 | Claude 正在背後幫你跑的事。**不用一直盯**,跑完會通知 |
| **Finished** | 已完成 | 跑完的任務數量 |
| **Running** | 執行中 | 還在跑 |
| **Clear** | 清除 | 把清單清空(只是清畫面,不影響已完成的工作) |

## 在 Code 分頁會看到的

| 英文 | 中文 | 白話說明 |
|---|---|---|
| **Select folder** | 選擇資料夾 | 告訴 Claude 要在哪個資料夾工作。**第一步就是這個** |
| **Accept** | 接受 | 同意這個修改,真的寫進檔案 |
| **Reject** | 拒絕 | 不要這個修改 |
| **diff** | 差異 | 綠色=要新增的內容,紅色=要刪掉的。**看懂再按 Accept** |
| **Allow / Deny** | 允許 / 不允許 | Claude 要動你的東西前的詢問。**看不懂就先按不允許**,再問它「剛剛那個是要做什麼」 |
| **Plan mode** | 規劃模式 | 只出計畫不動手。大工程先用這個看它想怎麼做 |

## 三個保命符(記這三個就不會怕)

1. **`Esc`** —— 隨時中斷 Claude 正在做的事
2. **權限詢問可以說「不」** —— 它動你的檔案前一定會先問
3. **git** —— 有存檔點就永遠能反悔(不會 git?直接說「幫我開啟版本控制」)
