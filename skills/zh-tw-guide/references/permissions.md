# 權限:它為什麼一直問我?

> 官方完整版:<https://code.claude.com/docs/zh-TW/settings>(權限章節)

## 設計理念

Claude Code 預設「不信任自己」:讀檔案通常不問,**要改檔案、跑指令時會先問你**。這不是故障,是安全帶。

## 你會看到的詢問類型

| 詢問 | 意思 | 新手建議 |
|---|---|---|
| 編輯檔案 | 要改某個檔案,會先顯示 diff | 看得懂就允許;看不懂先問「解釋這個修改」 |
| 執行指令(Bash) | 要跑終端機指令 | 唯讀類(`ls`、`git status`)可放行;`rm`、`curl`、安裝類先想想 |
| 一律允許(don't ask again) | 這類動作以後不再問 | 新手期先不要,多看幾次 diff 是學習 |

## 三種模式(Shift+Tab 切換)

- **default**:每個修改都問——新手期用這個
- **auto-accept edits**:改檔不問(跑指令仍問)——熟了再開
- **plan mode**:只規劃不動手——大任務先用這個看計畫

## 新手三原則

1. 看不懂的詢問就先「不允許」,然後問 Claude「剛剛那個是要做什麼?」——它會解釋,你不會弄壞東西。
2. 永遠可以按 `Esc` 中斷。
3. 別為了省事把所有東西設成一律允許;等你看得懂它在做什麼,再逐類放行(設定存在 `settings.json` 的 `permissions`)。
