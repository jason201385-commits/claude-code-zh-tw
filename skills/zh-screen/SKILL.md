# 畫面繁中對照卡

**下面的表格直接用,不需要讀任何檔案**(要更詳細的版本才去讀 `zh-tw-guide/references/screen-map.md`)。

## 回答規則

- **有指定某個東西**(例:「Artifacts 是什麼」)→ 只答那一項:中文名 + 一句白話用途 + 什麼時候會用到。三行內,不要整張表倒出來。
- **沒指定**→ 先給「左邊那排(側邊欄)」,然後問:「還要看輸入區、右上角背景任務,還是 Code 分頁?」使用者說要哪塊再給哪塊。
- 表格保留英文原文(他要對得上螢幕),中文放旁邊,說明要講「幹嘛用的」不是翻字面。
- **收尾固定一句**:「看不懂的東西直接問我,或按 `Esc` 中斷、權限詢問可以說不 —— 弄不壞的。」
- 畫面會隨版本改。跟他螢幕對不上時以他看到的為準,請他描述,不要硬套。
- guided 模式可加一句花生開場(最多一句)。

## 左邊那排(側邊欄)

| 英文 | 中文 | 白話說明 |
|---|---|---|
| Home | 首頁 | 一般聊天。問問題、寫東西、查資料都在這 |
| Code | 寫程式 | 讓 Claude 直接動你電腦裡的檔案。要先選一個資料夾 |
| New | 開新的 | 開全新對話,跟上一個完全無關(它不會記得剛才聊什麼) |
| Artifacts | 作品 | Claude 幫你做出來的成品(網頁、圖表、文件)存在這 |
| Routines | 自動任務 | 設定任務自動執行。**有分本機和雲端兩種** —— 本機的電腦關了就停 |
| Dispatch | 手機派工 | 從**手機**把工作交辦給**這台電腦**;電腦要開著、Claude 也要開著才會跑 |
| Customize | 自訂功能 | 管理工具與連線 —— 外掛、技能、連接器都在這 |
| More | 更多 | 展開看其他功能 |
| Settings | 設定 | 帳號、外觀、語言、連接器 |

側邊欄下半部是**你的對話清單**,點一下回到那個對話。

## 中間下面(輸入區)

| 英文 | 中文 | 白話說明 |
|---|---|---|
| Type / for commands | 打 / 看指令 | 打字的地方。**直接打中文就好**;想看快速指令先打一個 `/` |
| Auto | 自動 | 讓 Claude 自己選模型,不確定就維持這個 |
| ＋ | 加東西 | 附加檔案、圖片、資料夾 |
| 🎤 | 語音 | 用講的代替打字 |

## 右上角

| 英文 | 中文 | 白話說明 |
|---|---|---|
| Background tasks | 背景工作 | 查看正在跑的工作,**不用一直盯著它** |
| Finished | 已完成 | 跑完的任務數 |
| Running | 執行中 | 還在跑 |
| Clear | 清除清單 | 清空這個面板的清單。⚠️ 跟指令 `/clear` 不同,那個是清空對話重新開始(舊對話找得回來) |

## Code 分頁

| 英文 | 中文 | 白話說明 |
|---|---|---|
| Select folder | 選擇資料夾 | 告訴 Claude 在哪個資料夾工作,**第一步就是這個** |
| Accept | 接受修改 | 同意**套用檔案修改** —— 按了才會真的改檔案 |
| Reject | 拒絕修改 | 不要套用這個修改,不會傷到你的檔案 |
| diff | 修改差異 | **＋是新增,－是刪除**(顏色只是輔助)。看清楚再決定 |
| Allow / Deny | 允許 / 拒絕 | 准許它**執行某個動作**(跟 Accept 套用檔案修改不同)。看不懂就先按 Deny |
| Plan mode | 規劃模式 | 先規劃、**不改你的檔案**(它仍會讀檔案來想辦法)。大工程先用這個 |

## 三個保命符(新手記這三個就不用怕)

1. **`Esc`** — 停止它正在做的事。⚠️ **只停止,不會復原**;已改掉的檔案要用 git 或叫它改回來
2. **權限詢問可以說「不」** — 它動你的檔案前一定先問
3. **git** — 有存檔點就永遠能反悔(不會 git?說「幫我開啟版本控制」)

## 這幾個最容易搞混(2026-07 經 ChatGPT 查證修正)

| 常見誤解 | 正確 |
|---|---|
| Dispatch = 丟雲端跑 | ❌ 是**手機交辦給這台電腦**,電腦要開著 |
| Esc = 可以救回被改的檔案 | ❌ **只停止,不復原** |
| Needs input = 點開就好 | ❌ 點開不等於處理完,可能還要回答或按同意 |
| Accept = Allow | ❌ Accept 套用**檔案修改**;Allow 准許**執行動作** |

還有這幾個新手常遇到但沒在上表的:
`Cowork` 工作助手(處理文件與日常工作)、`Local` 本機執行(電腦關了就停)、
`Remote` 雲端執行(關電腦仍繼續)、`Ask permissions` 先問再做(新手建議)、
`Auto accept edits` 自動接受修改(⚠️ 它不會再問你)。
